# STUDY PRO — Telegram Mini App

Готовый стартовый проект: каталог, форма заявки и отправка заявки администратору в Telegram.

## Что входит
- `public/index.html` — интерфейс Mini App, адаптированный под телефон.
- `server.js` — сервер и API для заявок.
- Проверка подлинности `Telegram.WebApp.initData`.
- Уведомление администратору через Telegram Bot API.

Цены в каталоге — тестовые. Измените их в `public/index.html` перед публикацией.

## Перед запуском
Нужен Node.js 18+ и HTTPS-хостинг. Не вставляйте токен бота в HTML, переписку или публичный репозиторий.

Переменные окружения на хостинге:
- `BOT_TOKEN` — токен от BotFather (хранить только в Secrets/Environment Variables).
- `ADMIN_CHAT_ID` — Telegram chat ID администратора.
- `PORT` — обычно хостинг задаёт автоматически.

## Запуск на сервере
```bash
npm install
npm start
```

После публикации получите HTTPS URL, например `https://your-app.example`. Именно его укажите:
1. BotFather → Mini Apps → Menu Button → URL; Title: `Открыть STUDY PRO`.
2. BotFather → Mini Apps → Main App → URL.
3. Direct Links: URL приложения; короткое имя `catalog` (если поле просит short name).

В Main App можно выбрать Fullscreen.

## Как получить ADMIN_CHAT_ID
1. Откройте своего бота в Telegram и отправьте ему `/start`.
2. Временно запустите на сервере безопасный способ получить ID через собственный webhook/бот-обработчик или используйте проверенный инструмент для просмотра update. Не публикуйте ID вместе с токеном.
3. Укажите ID в переменных окружения хостинга.

## Важно
- Для уведомлений пользователь должен сначала открыть бота и нажать `/start`.
- Сервер проверяет подпись Telegram initData; форма не принимает заявки из обычного браузера.
- Не подключены платежи, загрузка файлов и личный кабинет статусов.
- Для цифровых товаров и услуг внутри Telegram действуют специальные правила оплаты Telegram Stars. Не пытайтесь обходить их сторонними платежами.
- Используйте приложение для оформления, дизайна, редактуры и учебной поддержки, а не для сдачи чужой работы как собственной.
